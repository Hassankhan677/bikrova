BIKROVA PWA — اردو ہدایات

یہ فولڈر BIKROVA کی انسٹال ہونے والی ویب ایپ (PWA) ہے۔

اہم:
1) PWA انسٹال کرنے کے لیے اسے HTTPS ویب ہوسٹنگ پر رکھنا ضروری ہے۔
2) اس ZIP کو اپنے کمپیوٹر پر extract کریں۔
3) index.html، manifest.webmanifest، sw.js اور icons فولڈر ایک ہی جگہ رہنے دیں۔
4) فولڈر کو کسی HTTPS static host پر publish کریں (مثلاً GitHub Pages)۔
5) Android پر Chrome میں اپنی شائع شدہ ویب سائٹ کھولیں۔
6) Chrome کے تین نقطوں والے مینو سے "Install app" یا "Add to Home screen" منتخب کریں۔
7) اب BIKROVA ہوم اسکرین پر ایپ آئیکن کے ساتھ نظر آئے گی۔

APK:
یہ پیکج خود APK نہیں ہے۔ APK بنانے کے لیے بعد میں اسے Android wrapper (مثلاً Capacitor یا Trusted Web Activity) میں پیک اور Android build/sign کرنا ہوگا۔ ابھی کوئی APK تیار یا Play Store پر شائع نہیں ہوئی۔

نوٹ:
Profit Calculator اور ابتدائی listing/ad templates مقامی طور پر چلتے ہیں۔ حقیقی AI generation کے لیے الگ AI API یا backend درکار ہوگا؛ اسے بعد میں محفوظ طریقے سے جوڑیں، API key کو HTML میں ظاہر نہ کریں۔
